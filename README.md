# 轻账 PersonalLedger

> 当前版本 **2.5.2**

一款个人本地记账 App：**没有账号、没有后端、没有广告**，所有数据只保存在你的设备上。
Kotlin + Jetpack 实现，天蓝色调的清新界面，支持浅色 / 深色 / 跟随系统。
直接安装 APK 即可使用，升级覆盖安装。

- **记一笔只要几秒**：金额、分类、备注、时间一次填完，忘了还能补记
- **账目管得明白**：搜索、组合筛选、分页浏览，图表报表一眼看懂
- **AI 助手（可选）**：一句话记账、改账、删账、统计，你确认后才落账
- **自动记账（实验性）**：监听微信 / 支付宝支付通知，自动解析入账
- **数据自己掌握**：CSV / PDF / JSON 导出，换机迁移，每天自动本地备份

## 功能

### 记账与账单

- **快速记账**：收入 / 支出，金额、分类、备注、时间一次填完；**时间可编辑**，补记昨天那笔、修正已有记录的时间都行
- **账单管理**：编辑、删除（带撤销）、按备注关键词搜索
- **组合筛选**：类型 / 分类 / 金额区间 / 日期区间随意组合；首页每页 10 条翻页浏览，记录多了也流畅

### 统计与报表

- **首页洞察卡**：本月最高支出分类、日均支出、与上月环比（上月没有支出时显示「—」，不编百分比）
- **报表页**：支出分类占比饼图 + 最近 7 天每日支出柱状图，附文字摘要
- **图表下钻**：点饼图的某个分类、或柱状图的某一天，直接看对应明细
- **饼图时间范围**：全部 / 近 7 天 / 近一个月 / 近三个月随时切换，下钻明细保持同一口径

### 预算

- **多条预算规则**：不限分类的总预算，或按分类的限额；周期可选每月 / 每周
- **首页进度条**：使用率 80% 预警、100% 超支，颜色随进度变化；有分类超支时额外提示
- **预算提醒**（可选）：达到 80% 或超支时发通知，同一周期内不重复提醒

### 数据导入导出与备份

- **导出**：CSV（带 BOM，Excel 直接打开不乱码）、PDF 报表、JSON 完整备份
- **导入**：支持本 App 导出的 CSV，也支持其他记账 App 的 CSV —— 导入前确认列映射（时间 / 类型 / 分类 / 金额 / 备注），**追加**不覆盖，无法解析的行会跳过并告知数量
- **恢复**：JSON 备份一键恢复，换机迁移就靠它
- **自动备份**（可选）：每天自动把完整备份写入应用专属目录，只保留最近 5 份，可任选一份恢复；全程不联网

### AI 助手（可选）

在「助手」页用一句话管账 —— 不只是记账，改账、删账、统计都能说：

| 你说 | 它做什么 | 要确认吗 |
|---|---|---|
| 「我今天买了咖啡 花了15」 | 解析成一笔待确认账目 | 要 |
| 「把昨天打车那笔改成 30」 | 找到那一笔，给出「原 → 改为」对照卡片 | 要 |
| 「删掉最后一笔」 | 逐项列出待删明细 | 要（且无法恢复） |
| 「这个月餐饮花了多少」 | 统计收支与分类占比，直接出数 | 不用，只读 |

**怎么开启**

1. 点助手页右上角「AI 设置」，填入 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请），选模型后保存。没填 Key 之前输入框是禁用的，不会出现「打完字才发现没配置」
2. 直接在输入框里说话。助手回一张卡片，核对无误点确认才生效；不对就点「忽略」

**几条用得放心的设计**

- **先确认，再落账**：新建 / 修改 / 删除都只出卡片，点确认之前账本一个字都不会变
- **找不到就反问**：匹配到多笔时把候选全部列出来请你补条件，不替你挑一笔
- **删除说清楚**：删除卡片逐项列明细，并标注「删除后无法恢复」—— 它没有撤销入口，所以确认前必须把话说清楚
- **账本不出设备**：模型只看到你说的话和分类名清单，找哪一笔、算什么数全部在本机完成（详见「隐私与权限」）

### 自动记账（实验性）

监听微信 / 支付宝的支付成功通知，自动解析金额、收支方向与分类并写入账本。
在设置里开启，需要授予系统「通知使用权」。解析错的账随时可以在账本里编辑修正，拿不准可以先开着对比几天。

### 个性化

- **主题**：浅色 / 深色 / 跟随系统，顶栏「外观」里切换、实时生效；可选开启 Material You 动态取色（跟随壁纸配色，需 Android 12+，默认关闭以保留固定的天蓝配色）
- **自定义分类**：收入 / 支出分类随便加，12 色板自选颜色并持久保存
- **字号**：应用内字号固定，不跟随系统「字体大小」缩放，大字体下界面不变形

## 隐私与权限

- **没有账号体系**，不收集任何个人信息，没有任何统计 SDK
- **全部数据存本机**：账本、预算、对话记录都只在你的设备上
- **唯一的联网功能是 AI 助手**（可选）：只发送你说的话、最近几轮对话与分类名清单；**账本记录从不上传** —— 改账、删账、统计所需的匹配与计算全部发生在本机
- **不填 API Key 时，应用不会发出任何网络请求**
- **API Key 只存本机**，并已排除在云备份与换机迁移之外
- **自动备份写在应用专属目录**，卸载即清理，不碰公有目录

| 权限 | 用在哪 |
|---|---|
| `INTERNET` | 仅 AI 助手请求 DeepSeek；未配置 Key 时不发起任何请求 |
| `POST_NOTIFICATIONS` | 预算预警通知（Android 13+ 属运行时权限） |
| 通知使用权 | 仅自动记账（实验性）解析支付通知，需手动开启 |

## 常见问题

**换机怎么迁移？**
设置里导出 JSON 备份 → 新机安装后导入即可。账目、预算规则、自定义分类都在备份里（对话记录不在）。

**误删了怎么办？**
账本里的删除带撤销；AI 助手确认后的删除无法撤销，但可以从 JSON 备份或自动备份恢复。所以自动备份建议开着。

**AI 助手要花钱吗？**
App 本身免费，但需要自备 DeepSeek API Key，模型调用费用由 DeepSeek 按量收取。一次请求用量很小，且系统提示词部分命中缓存有大幅折扣，日常使用成本很低。

**自动记账会出错吗？**
它是实验性功能，按通知内容解析金额与分类，解析错的账随时可以在账本里修改。建议先开着和手动记账对比几天，满意再依赖它。

## 技术栈

Kotlin + Jetpack（Room / DataStore / WorkManager / ViewModel / LiveData）、Material Components、MPAndroidChart。单模块工程，109 条纯 JVM 单元测试，不依赖设备与网络。
